## 关键实测结论（276 张 11 类固定评估集）

| 结论 | 数据 |
|---|---|
| 单轮评估不可信 | 276 张 3 轮极差 2.2pt；60 张子集极差 5.0–6.7pt，且**符号会翻转** |
| 详细版提示词显著更优 | 64.3% vs 简洁版 58.5%，−5.8pt，p=0.0019（合并 p=0.00002） |
| 默认 0.6 阈值形同虚设 | 只拦下 1.8% 的错误；跨轮分歧是更好的信号（挡错 26.6%/误挡 10.2%） |
| 但约一半错误拦不住 | 最好的规则也只能拦 46%，另一半"既自信又稳定" |
| 多数投票不划算 | 3 轮投票仅 +0.5pt，等于多花 2 倍钱 |
| 快速模式 | 快 2.3 倍、token 少 32%，但准确率点估计 −3~−5pt（合并 p=0.064）→ **默认关** |
| 吞吐基线 | 6 并发 + 240 张/分 = 93 张/分（旧基线 45 张/分） |

## 待办（按优先级）

1. **补齐评估集类别不平衡**：动漫仅 3 张、游戏 13 张，这两类的数字不可用 → 补到每类 ≥30 张
2. **针对单个混淆对做提示词 A/B**（`政治→动漫`、`地理/学习/科技→日常` 是主要失分点），
   一次只改一条规则，用「重复轮次 3 + A/B」验证 —— 已证明整篇重写是负收益
3. 最差三类（历史 43–50%、政治 50–60%、游戏 38–54%）的类别定义本身可能需要重新划分
4. 可选：若要让快速模式默认开启，需每类 ≥30 张 × 4 轮以上确认等价（约 ¥6）
