## 关键实测结论（273 张固定评估集，8 类体系）

| 结论 | 数据 |
|---|---|
| **8 类改版：数字涨了，但模型没变聪明** | 63.4% → 68.5%；配对检验 p=1.0000（12:11）→ 收益 100% 来自类别变粗 |
| 具体类别精确率 | 74.9%（模型"敢下结论"时约 1/4 是错的） |
| 有害错误 56 张（原 75） | 无害回流（→日常）29 张 |
| **过度预测会转移不会消失** | 删「动漫」（精确率 12.5%）后，「游戏」成了新重灾区（35.7%） |
| 轮间极差 | 8 类 0.7pt ／ 11 类 2.2pt ／ 60 张子集 5.0–6.7pt（样本越少越不稳） |
| 跨轮一致率仍是最佳错误信号 | 一致组 73.8% vs 分歧组 43.2%（差 30.6pt） |
| 单轮评估不可信 | 60 张子集上「关思考」首轮 −3.3pt，重复 3 轮翻转为 +1.7pt |
| 详细版提示词显著更优 | 64.3% vs 简洁版 58.5%，p=0.0019（合并 p=0.00002） |
| 默认 0.6 阈值形同虚设 | 只拦下 1.2% 的错误；**没有任何错误样本置信度均值 < 0.6** |
| 最多只能拦下一半错误 | 最好的规则拦 46%，另一半"既自信又稳定" |
| 多数投票不划算 | 3 轮投票仅 +0.4pt，等于多花 2 倍钱 |
| 快速模式 | 快 2.3 倍、token 少 32%，准确率点估计 −3~−5pt（合并 p=0.064）→ **默认关** |
| 吞吐基线 | 6 并发 + 240 张/分 = 93 张/分 |
